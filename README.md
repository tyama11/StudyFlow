# 📖 StudyFlow - 受験生・学習者のための学習時間記録 & TODOアプリ

[![Build Status](https://img.shields.io/badge/build-passing-brightgreen)](#)
[![Platform](https://img.shields.io/badge/platform-macOS%20%7C%20Windows%20%7C%20Linux-blue)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**StudyFlow** は、日々の勉強時間をリアルタイムで計測・記録し、TODOタスクと一緒に一元管理できるデスクトップアプリケーションです。  
直感的なタイマー操作で勉強時間を記録し、過去の学習記録や達成したタスクをカレンダーからいつでも振り返ることができます。

> **🔒 完全ローカル保存 & オフライン対応**  
> 勉強データはすべてお使いのPC内に安全に保存されます。外部サーバーへの個人情報送信は一切行われないため、オフライン環境でも安心してご利用いただけます。

---

## 🚀 アプリのダウンロード & インストール

お使いの OS に合わせた最新版をダウンロードしてご利用ください。

### 📥 ダウンロード方法
1. 本リポジトリの **[Releases](../../releases)** または **[Actions](../../actions)** の最新ビルド結果（ページ最下部の **Artifacts**）を開きます。
2. お使いの OS に対応したファイルをダウンロードします：
   - 🍎 **macOS**: `study-flow-macos.zip` (解凍すると `.dmg` または `.app` が入っています)
   - 🪟 **Windows**: `study-flow-windows.zip` (解凍すると `.exe` または `.msi` が入っています)
   - 🐧 **Linux**: `study-flow-linux.zip` (解凍すると `.AppImage` または `.deb` が入っています)

---

### 💻 OS別 起動・インストール手順

#### 🍎 macOS をご利用の場合
1. ダウンロードした zip を展開し、`.dmg` ファイルをダブルクリックします。
2. 表示されたウィンドウで `StudyFlow` アイコンを「Applications（アプリケーション）」フォルダにドラッグ＆ドロップします。
3. アプリケーションフォルダから `StudyFlow` を起動します。
   > **初回起動時の注意（セキュリティ警告が出た場合）:**  
   > 「開発元が未確認のため開けません」と表示された場合は、アプリアイコンを **「右クリック（または Control を押しながらクリック）→ 開く」** を選択し、ダイアログの「開く」をクリックしてください。  
   > または、Macの **「システム設定」→「プライバシーとセキュリティ」** 画面下部の「このまま開く」をクリックすることでも起動できます。

#### 🪟 Windows をご利用の場合
1. ダウンロードした zip を展開し、`.exe`（インストーラー）を実行します。
2. 画面の指示に従ってインストールを完了してください。
   > **初回起動時の注意（SmartScreen 警告が出た場合）:**  
   > 「WindowsによってPCが保護されました」と表示された場合は、画面内の **「詳細情報」** をクリックし、現れた **「実行」** ボタンを押してください。

#### 🐧 Linux をご利用の場合
- `.AppImage` の場合: ファイルのプロパティから「実行権限」を付与するか、ターミナルで `chmod +x study-flow.AppImage` を実行してから起動してください。
- `.deb` の場合: `sudo dpkg -i study-flow_*.deb` でインストールできます。

## ✨ 主な機能と使い方

### 1. ⏱️ 学習時間タイマー（Start / Stop 記録）
- **ワンクリック計測**:
  - **`Start` ボタン**: ストップウォッチが開始し、学習時間を秒単位で計測します。
  - **`Stop & 記録` ボタン**: 計測を終了し、科目や簡単なメモを入力して本日の学習ログにワンタップ保存します。
- **TODOタスクとの連動**:
  - TODOリストにあるタスク横の再生ボタンを押すと、そのタスク名を対象にしたタイマーが即座に起動します。
- **ポモドーロモード（25分集中タイマー）**:
  - 「ポモドーロ」に切り替えることで、25分間のカウントダウン集中タイマーとしても活用できます。

---

### 2. 📝 TODOタスク管理
- **タスクの追加**: タスク名、科目（英語・プログラミング・数学など）、予定目安時間、メモを設定してタスクを追加できます。
- **進捗管理**: 完了したタスクにチェックを入れると、達成日時が自動記録され、サイドバーの進捗バーに反映されます。
- **絞り込みフィルター**: 「すべて」「未完了」「完了済み」の切り替え表示に対応。

---

### 3. 📅 過去データの読み出し & カレンダー振り返り
- **任意の日付を選択**: 「過去のデータ & 統計」タブでカレンダーから過去の日付を選ぶだけで、その日の実績を即座に読み出せます。
- **その日の学習サマリー**:
  - 総学習時間
  - 完了したTODO数と達成率
  - 最も時間を費やした科目
- **学習タイムライン一覧**: その日に「何時から何時まで」「何の科目を何分勉強したか」のセッション履歴を時系列で確認・管理できます。

---

### 4. 📊 統計グラフ（週間学習トレンド）
- 直近7日間の学習時間の推移を美しい棒グラフで自動可視化。
- 日ごとの学習量の波を把握し、学習習慣の維持・改善に役立ちます。

---

### 5. 💾 データ管理 & バックアップ
- **JSON エクスポート**: 全てのTODOと学習記録を1つのJSONファイルとしてワンクリックで保存できます。
- **JSON インポート**: 保存したバックアップファイルを読み込んで、いつでもデータを復元できます。
- **PC移行も安心**: 新しいパソコンに移行する際も、エクスポートしたファイルを読み込むだけでこれまでの学習ログを完全に引き継げます。

- **チャート描画**: Canvas API (外部ライブラリ非依存・軽量設計)
- **CI/CD**: GitHub Actions (クロスプラットフォーム自動ビルド)
