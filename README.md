# 📖 StudyFlow - 学習時間記録 &amp; TODOアプリ

**StudyFlow** は、日々の勉強時間をリアルタイムで計測・記録し、TODOタスクと一緒に一元管理できる学習サポーターアプリです。  
Webブラウザからすぐに使えるほか、macOS および Windows のデスクトップアプリとしても利用できます。

- 🌐 **Web版（インストール不要）**: [https://tyama11.github.io/StudyFlow/](https://tyama11.github.io/StudyFlow/)
- 💻 **デスクトップ版（オフライン対応）**: [最新リリース一覧からダウンロード](https://github.com/tyama11/StudyFlow/releases/latest)

---

## ✨ 主な機能と使い方

### 1. ⏱️ 学習時間タイマー（計測 &amp; 記録）
- **ストップウォッチ計測**: `Start` ボタンを押すと秒単位で勉強時間を計測します。終了時は `Stop &amp; 記録` を押し、科目やメモを入力して保存します。
- **ポモドーロモード**: 25分（または好みの分数）のカウントダウンタイマーとして集中学習を行えます。
- **TODO連動**: TODOリストにあるタスク横の再生ボタンを押すと、そのタスク名を対象にしたタイマーが即座に起動します。
- **リセット**: `リセット` ボタンでタイマーを初期値に戻せます。

### 2. 📝 本日の記録の確認・編集・削除
- **編集 (✏️)**: 記録済みの科目、学習時間（分単位）、メモを後から微調整できます。
- **削除 (🗑️)**: 誤って記録したセッションをいつでも破棄可能。合計時間や目標達成率にも即時反映されます。

### 3. 🎯 1日の目標設定
- **選べる達成基準**: 「**学習時間基準**（例: 1日3時間）」または「**タスク数基準**（全タスク完了 / 指定個数）」から選択できます。
- **リアルタイム進捗**: 本日の達成率がプログレスバーに反映され、目標達成時にはお祝いバッジと演出が表示されます。

### 4. 🍅 ポモドーロタイマー &amp; アラーム音
- **集中時間の変更**: 15分/20分/25分/30分/45分/50分/60分のクイック選択や、自由な分数指定が可能です。
- **アラーム通知**: 時間になると心地よいBGM（『かえるのピアノ』）が流れ、ワンクリックで集中した時間をそのまま学習ログへ記録できます。
- **サウンド設定**: 設定タブから音のON/OFFや音量調整、テスト試聴が可能です。

### 5. 📝 TODOタスク管理
- タスク名、科目、予定時間、メモを設定して追加。
- チェックを入れると完了状態になり、打ち消し線で分かりやすく整理されます。

### 6. 📊 統計グラフ &amp; 振り返り
- **週間推移グラフ**: 直近7日間の学習時間を棒グラフで可視化。バーにカーソルを合わせると詳しい時間を確認できます。
- **過去データの読み出し**: カレンダーから過去の日付を選ぶだけで、その日の総学習時間やタイムライン履歴を振り返ることができます。
- **累計実績**: これまでの全学習時間、累計セッション数、達成タスク数、総学習日数、科目別の割合を表示します。

### 7. 📚 科目・分野のカスタマイズ
- 「設定 &amp; データ」タブから、資格試験（英検、簿記、プログラミングなど）や学校の科目など、学びたい科目を自由に追加・色指定・編集・削除できます。

### 8. 🌓 ダークモード / ライトモード切り替え
- OSのシステム設定に自動連動するほか、サイドバーの切り替えボタンから手動でダーク / ライト / OS連動 を変更できます。

### 9. 💾 データのバックアップ &amp; 復元
- **データはすべてローカル保存**: ブラウザまたはPC内に安全に保存され、外部サーバーには送信されません。
- **エクスポート / インポート**: 全データを JSON ファイルとして1クリックでバックアップ・復元できるため、PCの買い替え時も安心です。
