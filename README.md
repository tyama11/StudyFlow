# 📖 StudyFlow - 学習時間記録 &amp; TODOアプリ (macOS Universal &amp; Windows対応)

[![Build Status](https://img.shields.io/badge/build-passing-brightgreen)](#)
[![Platform](https://img.shields.io/badge/platform-macOS%20(Universal)%20%7C%20Windows-blue)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**StudyFlow** は、日々の勉強時間をリアルタイムで計測・記録し、TODOタスクと一緒に一元管理できるデスクトップアプリケーションです。  
**macOS（Intel Mac &amp; Apple Silicon M1〜M4 両対応の Universal Binary）** および **Windows** に対応しています。

> **🔒 完全ローカル保存 &amp; オフライン対応**  
> 勉強データはすべてお使いのPC内に安全に保存されます。外部サーバーへの個人情報送信は一切行われないため、オフライン環境でも安心してご利用いただけます。

---

## 🚀 アプリのダウンロード &amp; インストール手順

### 📥 1. アプリのダウンロード
1. 本リポジトリの **[Actions](../../actions)** の最新ビルド結果（ページ最下部の **Artifacts**）を開きます。
2. お使いの OS に合わせたファイルをダウンロードします：
   - 🍎 **macOS (Intel &amp; M1/M2/M3/M4両対応)**: `study-flow-macos-universal.zip`
   - 🪟 **Windows**: `study-flow-windows.zip`

---

### 💻 2. インストール &amp; 起動手順

#### 🍎 macOS をご利用の場合
1. ダウンロードした `study-flow-macos-universal.zip` をダブルクリックして展開します。
2. 展開された `.dmg` ファイルを開きます。
3. `StudyFlow` アイコンを「Applications（アプリケーション）」フォルダにドラッグ＆ドロップします。
4. アプリケーションフォルダから `StudyFlow` を起動します。
   > **💡 初回起動時の注意（セキュリティ警告が出た場合）:**  
   > 「開発元が未確認のため開けません」と表示された場合は、アプリアイコンを **「右クリック（または Control を押しながらクリック）→ 開く」** を選択し、ダイアログの「開く」をクリックしてください。

#### 🪟 Windows をご利用の場合
1. ダウンロードした `study-flow-windows.zip` を展開します。
2. `.exe`（NSIS インストーラー）を実行します。
   > **💡 初回起動時の注意（SmartScreen 警告が出た場合）:**  
   > 「WindowsによってPCが保護されました」と表示された場合は、画面内の **「詳細情報」** をクリックし、現れた **「実行」** ボタンを押してください。

## ✨ 主な機能と使い方

### 1. ⏱️ 学習時間タイマー（Start / Stop &amp; 記録 / リセット）
- **`Start` ボタン**: ストップウォッチが開始し、学習時間を秒単位でリアルタイム計測します。
- **`Stop &amp; 記録` ボタン**: 計測を終了し、科目やメモを入力して本日の学習ログにワンタップ保存します。
- **`リセット` ボタン**: いつでもワンクリックでタイマーを `00:00:00`（またはポモドーロ `25:00`）に戻せます。
- **TODOタスク連動**: TODOリストにあるタスク横の再生ボタンを押すと、そのタスク名を対象にしたタイマーが即座に起動します。
- **ポモドーロモード**: 25分間のカウントダウン集中タイマーとしても利用可能。

### 2. 📝 本日の記録一覧の「編集」と「破棄（削除）」
- 本日の記録一覧（Recent Sessions）にある各行から：
  - **✏️ 編集ボタン**: 科目の変更、学習時間（分単位）の微修正、メモの追加・編集が可能。
  - **🗑️ 破棄ボタン**: 誤って計測した記録をいつでも削除可能。合計学習時間や達成率にも即時反映されます。

### 3. 🌓 OS連動 &amp; 手動ダーク/ライトモード切り替え
- OSのシステム設定（ダークモード / ライトモード）に合わせて背景色が自動で切り替わります。
- サイドバー左下の「🌓 テーマ切り替え」ボタンから、手動でダーク / ライト / OS連動 を切り替えることも可能です。

### 4. 📝 TODOタスク管理（一覧表示）
- タスク名、受験科目、予定目安時間、メモを設定して追加。
- チェックを入れると打ち消し線が引かれ、完了状態として一覧に分かりやすく残ります。

### 5. 📅 過去データの読み出し &amp; カレンダー振り返り
- カレンダーから過去の日付を選ぶだけで、その日の総学習時間、完了TODO数、タイムライン履歴を瞬時に読み出して振り返ることができます。

### 6. 📊 統計グラフ（週間学習推移）
- 直近7日間の学習時間の推移を美しい棒グラフで自動可視化。

### 7. 💾 データ管理 &amp; バックアップ
- **JSON エクスポート / インポート**: 全てのデータを1クリックでバックアップ・復元可能。PC買い替え時も安心です。
